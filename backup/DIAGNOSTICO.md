# Diagnóstico do Horizonte antigo (09/11/2026)

## O que existia
- Um único arquivo HTML publicado como página no Claude (`horizonte-antigo/horizonte.html`), mais três versões anteriores (`horizonte_v1..v3.html`).
- Não havia repositório Git, backend, banco de dados nem dependências instaladas.

## Tecnologias
- HTML, CSS e JavaScript puro.
- WebGL 2 para a galáxia 3D e os mini planetas.
- Capacidade `sample` do Claude para o chat do agente.

## Funcionalidades antigas
- Painel visual de "agentes de IA": galáxia 3D, 17 skills num arco, 34 notas como mini planetas.
- Painel com notificações, calendário e objetivos (todos dados de exemplo).
- Chat com um agente que só funcionava dentro do Claude.

## O que foi reaproveitado
- O nome HORIZONTE e a cor dourada da identidade (#e8b75a).
- As fontes tipográficas IBM Plex Sans e IBM Plex Mono.

## O que foi removido
- Todo o resto: galáxia, skills, notas, calendário, objetivos, o chat via Claude e os dados de exemplo. Nada disso tem relação com a central editorial.
